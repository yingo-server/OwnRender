# 效果与样例

本仓库**不附带任何渲染产物**，请自行渲染验证。本文说明"什么设置会得到什么画面"。

---

## 1. 一句话理解它的行为

> 光照由 **太阳/月亮的位置** 决定；而太阳在哪儿，由 **时间 + 经纬度 + 窗户朝向** 决定。

所以调效果的第一顺位不是改参数，而是**问自己**：

1. 现在几点（当地时间）？
2. 在哪（经纬度）？
3. 窗朝哪边（东 / 西）？
4. 天上有云吗？

这四个确定后，画面基调基本就定了。

---

## 2. 时间 × 朝向：什么时候有光斑

`--window-orientation right` = 东向窗，`left` = 西向窗。

| 当地时间 | 太阳状态 | 东窗（right） | 西窗（left） |
|---|---|---|---|
| 05:00 – 07:00 | 低角、偏暖 | **有直射**，光斑拉长、偏橙 | 无直射 |
| 07:00 – 10:00 | 中高角 | **有直射**，光斑清晰、位置随太阳移动 | 无直射 |
| 10:00 – 14:00 | 高角、接近头顶 | 直射**很弱**（太阳接近窗平面），画面主要靠天光 | 同左 |
| 14:00 – 17:00 | 中高角 | 无直射 | **有直射** |
| 17:00 – 19:00 | 低角、暖 | 无直射 | **有直射**，光斑拉长偏橙红 |
| 19:00 – 05:00 | 地平线下 | 无直射；有月光时是冷蓝白弱光斑 | 同左 |

> 这是**物理正确**的行为，不是 bug。很多人第一反应"中午怎么没光斑"——
> 因为东窗在正午确实接不到直射光。

## 4. 文字（叠字）效果

文字合成模型是**乘性反射**，不是简单覆盖：

```
L_out = L_wall · (1 − occ·s) · [(1−α) + α·ρ]
                ↑ 接触阴影          ↑ 朱红反射率
```

- `α` = 文字不透明度（0 全透明、1 全实心）
- `ρ` = 朱红反射率（`--cinnabar`，默认 `0.52 0.055 0.048`）

**这意味着**：字在暗处会跟着变暗 —— 因为它是"颜料"，不是"贴纸"。

### 三种风格

| 风格 | 参数 | 观感 |
|---|---|---|
| **清晰现代** | `--noise-low 0.05 --noise-mid 0.04 --noise-high 0.02 --diffusion 0.10 --oxidation 0` | 边缘干净锐利，接近印刷；适合石材、瓷砖 |
| **默认** | 不加参数 | 轻微斑驳、边缘略毛，有细微氧化颗粒 |
| **斑驳旧标语** | `--noise-low 0.30 --noise-mid 0.20 --noise-high 0.12 --diffusion 0.40 --oxidation 0.5` | 大幅斑驳、边缘发毛、颗粒明显；适合旧石灰、草泥墙 |
| **吃进墙里** | `--material-coupling 0.5` | 字形透明度随墙面材质起伏（凸处实、凹处虚）；粗砖石墙很出效果 |

### 字号

| `--font-ratio` | 适用 |
|---|---|
| 0.08 – 0.12 | 长句、留白多 |
| 0.15 – 0.22 | 两行题字（默认 0.18） |
| 0.28 – 0.40 | 短句、视觉冲击（建议 ≤ 4 字） |

## 5. 画面微调

| 想要 | 参数 |
|---|---|
| 整体更亮、更"通" | `--exposure 1.1 ~ 1.3` |
| 压暗、更有氛围 | `--exposure 0.8 ~ 0.95` |
| 去色、更克制 | `--saturation 0.6 ~ 0.8` |
| 增强材质色感 | `--saturation 1.1 ~ 1.3` |

> 曝光/饱和度作用在 ACES 之后，所以**不会**破坏高光滚降（不会一调亮就死白）。

## 6. 材质选择建议

| 想要的氛围 | 推荐底图 |
|---|---|
| 现代极简 | 微水泥、白色乳胶漆、莫兰迪涂料 |
| 工业 / 粗粝 | 清水混凝土、水泥砌块、锈蚀钢板 |
| 传统 / 岁月 | 青砖墙、旧石灰、草泥墙、暖色夯土 |
| 高级 / 精致 | 大理石、木饰面、瓷砖 |
| 厚重 / 城市 | 红砖墙、石砌墙 |

**经验**：纹理越细的墙（微水泥、乳胶漆），光斑越干净；砖石类会产生更明显的
局部起伏，此时配 `--material-coupling` 效果更好。

## 7. 自己验证：数值自检

不用肉眼看，也能判断结果是否正常。

### ① 检查平光底图

中心区亮度 vs 四角区亮度，差值应尽量小（< 15/255 为佳）：

```python
from PIL import Image
import numpy as np
a = np.asarray(Image.open("background/微水泥.png").convert("RGB"),
               dtype=np.float32)
h, w, _ = a.shape
cy, cx = h // 4, w // 4
ctr = a[cy:cy*3, cx:cx*3].mean()        # 中心区
crn = np.concatenate([a[:cy, :cx].reshape(-1,3),
                      a[:cy, -cx:].reshape(-1,3),
                      a[-cy:, :cx].reshape(-1,3),
                      a[-cy:, -cx:].reshape(-1,3)]).mean()
print("中心", round(ctr,1), "四角", round(crn,1), "差", round(ctr-crn,1))
```

> 差值大 → 底图自带光照 → 会在重光照时被"拉平"，建议换图。

### ② 检查成图是否符合预期时间

```python
from PIL import Image
import numpy as np
a = np.asarray(Image.open("output/LIT_xxx_final.png").convert("RGB"),
               dtype=np.float32)
print("平均亮度", round(a.mean(),1), "RGB", np.round(a.reshape(-1,3).mean(0),1))
```

| 时刻 | 合理亮度区间（参考） |
|---|---|
| 正午晴 | 140 – 190 |
| 上午/下午晴 | 120 – 180 |
| 黄昏 | 80 – 150 |
| 深夜 | 20 – 50 |

> 如果"白天却只有 30 多"，说明底图或参数有问题（例如时间被当成了 UTC）。

### ③ 检查光斑

光斑是画面中**明显亮于周围**的区域。若 `--weather clear` 且白天却完全看不到
亮区，检查窗户朝向与太阳相对方位是否"背向"（见第 2 节）。

## 8. 复现性

想固定噪声分布（让同参数的两次渲染完全一致）：

```bash
python main.py --offline-bg 微水泥 --seed 12345 -y
```

不指定则每次随机。
