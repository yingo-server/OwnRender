# 常见问题

---

## 启动 / 依赖

**Q：`ModuleNotFoundError: No module named 'numpy'`**
装依赖：`pip install numpy Pillow requests`。如果用的是 venv，确认运行的是同一个解释器。

**Q：没有 `requests` 能跑吗？**
能。离线光照 + 叠字不需要它。AI 生成、NTP、IP 定位、实时天气会不可用。

**Q：Windows 上输出一堆乱码 / 颜色怪异？**
程序会自动检测 ANSI 支持并降级；也可显式加 `--no-color`，或用
`set PYTHONIOENCODING=utf-8`。

## 定位相关

**Q：`--gps` 说"全部不可用"？**
按环境补依赖：

| 环境 | 需要 |
|---|---|
| Termux | `pkg install termux-api` 并安装 Termux:API 应用 |
| Android（有 root/Shizuku） | 设置中心 → 凭据 → 本机定位 → **开启 su 提权** |
| Linux 桌面 | `apt install geoclue-2.0`（提供 `where-am-i`）/ `gpsd` / `modemmanager` |
| macOS | `brew install CoreLocationCLI` |
| Windows | 系统设置里允许应用访问位置 |

实在拿不到就直接给坐标：

```bash
python main.py --set-location "39.9042,116.4074,北京"
python main.py --offline-bg 微水泥 --gps -y     # 命中缓存
```

**Q：`--ip-loc` 出来的城市不对？**
IP 定位依赖出口 IP，用了代理/VPN 就会定位到代理所在地。多个服务结果不一致是正常的
（向导里会把**所有结果列出来让你挑**）。

**Q：怎么查看定位链路的诊断？**
TUI → `信息 → 定位测试`，会逐条列出：当前环境、时区、8 个 provider 的可用性、
实际尝试结果、缓存、各 IP 服务返回。

## 时间

**Q：明明设了中午 12:00，画面却是深夜？**
`--time` 的时区语义。光照按 **UTC** 计算：

- 写 `2025-06-21 12:00`（不带偏移）→ 按**本机时区**解释
- 如果本机时区是 UTC，那就等于 UTC 12:00；对东八区来说当地已是 20:00（天黑了）

**推荐**：直接写带偏移的 ISO 串 —— `2025-06-21T12:00:00+08:00`。

**Q：午夜附近为什么完全没有光？**
可能月亮在地平线下，或者月相接近新月（月光极弱）。TUI 的天气/光照预测里会显示
`可达性`，会写明原因。

## 光照效果

**Q：正午没有光斑？**
**这是物理正确的**。东向窗在正午太阳接近窗平面，几乎接不到直射；
西向窗同理在上午没有直射。见 [效果与样例](效果与样例.md) 第 2 节。

**Q：白天画面还是死黑？**
两个可能：
1. 时间实际是 UTC（见上一节）；
2. 底图自带强光照，Retinex 把它当作"原始光照"剥掉了。
   自检方法见 [效果与样例](效果与样例.md) 第 7 节。

**Q：光斑边界太硬 / 太软？**
- 太硬 → 提高云量或换 `cloudy`/`overcast`/`haze`
- 太软 → 用 `clear`，并检查 `--grid-frame`（窗框占比）是否过大

**Q：墙面整体太亮 / 太暗？**
先用 `--exposure 0.9` 或 `1.1` 微调；若还不够，再动
设置中心 → 光照与 3D 场景里的 `ambient_target_*` 系列。

## 文字叠字

**Q：文字发糊 / 边缘糊成一片？**
- 提高 `--ssaa`（如 12/16）
- 降低 `--diffusion`（默认 0.20；想干净可给 0.10）
- 降低 `--noise-low`

**Q：文字太斑驳、几乎看不清？**
把 `--noise-low/--noise-mid/--noise-high` 降到 0.05 左右，`--oxidation 0`。

**Q：文字颜色不对 / 太暗？**
朱红是**反射率**（乘性），不是覆盖色。默认 `0.52 0.055 0.048`；
想更亮可以 `--cinnabar 0.7 0.1 0.06`，想更沉就降低红通道。

**Q：字体列表是空的？**
检查 `fonts/` 是否存在且含 `.ttf/.otf/.ttc/.otc/.woff/.woff2` 文件。

**Q：断行不符合预期？**
规则是：`,`→`，`，按 `，` 切分并在行尾保留逗号。
想强制分行用显式换行（TUI 里直接分多行输入，或 CLI 里传 `\n`）。

## 性能 / 内存

**Q：很慢 / 占内存大？**
主要开销在文字 SSAA：`--ssaa N` 会分配 `宽×N × 高×N` 的灰度画布。

| 底图尺寸 | SSAA 8 | SSAA 4 |
|---|---|---|
| 1312×736 | ≈ 10496×5888（60MB 灰度） | ≈ 5248×2944（15MB） |

建议：`--ssaa 4` 起步，最终成图再上 8。

**Q：想只出光照底图不叠字？**
把文字步骤关掉（向导 `[0] 文字` → 是否叠加 → n），或命令行 `-t ""`。
