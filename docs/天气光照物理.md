# 天气光照物理 —— 为什么"雨天发闷"以及修了什么

> 结论先说：**显示异常几乎都是"参数没对接"**，不是"亮度旋钮没拧对"。
> 本次修复把 API 的每一个字段都接进了计算，并且**删掉了所有手调的"天气风格表"**，
> 全局手调参数压到 **5 个**，其余全部由物理关系与几何推导。

---

## 一、问题（实测证据）

同一正午、只换天气，把渲染结果量化（`logY` 对数平均亮度；`p1/p99` 是1%与99%分位）：

| 天气 | logY | p1 | p99 | 动态范围 | 结论 |
|---|---|---|---|---|---|
| clear | 0.324 | 0.345 | 0.650 | 0.305 | 晴天也没有真正的高光/暗部 |
| cloudy | 0.257 | 0.308 | 0.589 | 0.281 | |
| overcast | 0.136 | 0.224 | 0.444 | 0.220 | |
| **rain** | 0.156 | 0.241 | 0.470 | 0.229 | **和"阴"几乎无差别** |
| **snow** | 0.136 | 0.224 | 0.444 | 0.220 | **和"阴"逐位相同**，还比晴天暗 2.4 倍（物理反了） |
| haze | 0.280 | 0.321 | 0.611 | 0.290 | |

两个硬伤：
1. **动态范围塌缩** —— 整张图挤在 0.22~0.44 的窄灰带里，没有暗部也没有高光。
2. **天气只改"整体亮度"** —— 晴/阴/雨/雪彼此的对比度、饱和、色温完全一样，
   于是"雨天"和"阴天"渲染出来根本分不出来。

另外：夜间 `00:00` 与 `04:00` 两帧**逐像素相同**（实测数值完全一致）。

## 二、根因：8 个缺项（不是参数没调好，是东西没接上）

| # | 缺什么 | 旧实现的实际行为 | 后果 |
|---|---|---|---|
| 1 | **湿度/降水/气温/天气码没接** | `WEATHER_PRESETS` 里没有 `temp`；`WeatherInfo.temp` 恒为 20℃；WMO `code` 拿到了但没人用 | 雪天被判成雨天（`temp<2` 永远不成立），雷阵雨被当成"一直下的小雨" |
| 2 | **云的物理语义错** | `_mie_tau()` 把 `cloud` 当成 **Mie 气溶胶**塞进光学厚度：`tau += (cloud/100)**1.5*1.8` | 云量变成"整体变暗旋钮"，既不产生"漫射变多"，也不产生"云缝露太阳" |
| 3 | **漫射/直射没有分离** | 直射与漫射各自糊在一起，没有云修正因子与能量守恒 | 多云时直射没被正确削减、漫射没被正确增强 |
| 4 | **环境光是全图常数** | `ambient = albedo * color * strength`，一个标量打过全图 | 没有直射光斑的天气（阴/雨/雪/雾）整张图是一块平灰 → 动态范围塌缩 |
| 5 | **地面反弹缺失** | 完全没有这一项 | 雪天（地面反照率 0.8）渲染得比晴天还暗 |
| 6 | **湿面缺失** | 降水只用于"玻璃水痕"贴图 | 雨天表面该变暗、变光、镜面增强，全都没有 |
| 7 | **空气光缺失** | 完全没有 | 雾天没有"空气感"（但注意：室内只有几米光程，**真实的空气光本来就只有百分之几**，不能硬凑） |
| 8 | **夜间照明是常数** | 夜间环境光恒为 0.02，与月亮高度/月相/云量无关 | 整段夜景是静止画面（延时视频后半段直接卡住） |

还有一项**感知层**缺失：**没有视觉适应（曝光适应）**。
晴天正午总照度 ≈ 1.0，阴雨天只有 ≈ 0.2~0.5。直接把辐照度当绝对亮度渲染，
阴雨天就必然是"晴天的四分之一亮" → 观感就是发闷、像坏掉。
人眼/相机是会自动曝光的（Stevens 幂律 B ∝ L^γ），这一步以前完全没有。

## 三、方案（`frame_light/atmosphere.py`）

### 3.1 只保留 5 个全局手调参数（全部有出处）

| 参数 | 值 | 依据 |
|---|---|---|
| `EYE_ADAPT_GAMMA` | 0.40 | 视觉适应幂律指数（Stevens 幂律，文献 0.33~0.5） |
| `TAU_CLOUD_THICK` | 3.0 | 厚云光学厚度 → 直射透过率 e⁻³ ≈ 5% |
| `WATER_FILM_REF_MM` | 0.50 | 降水率到 0.5 mm/h，表面水膜接近全覆盖 |
| `GROUND_ALBEDO` | 雪 0.80 / 湿 0.07 / 干 0.25 | 材料反照率常数 |
| `TONE_S_CURVE_GAIN` | 0.30 | 光硬度 → 对比度的映射增益 |

教科书常数（非可调）：`KOSCHMIEDER_K = 3.912`、`TWILIGHT_ALT_DEG = 10°`。
自测 `G12` 会**强制检查**这条约束：`atmosphere` 模块里不允许出现第 6 个可调大写常量。

### 3.2 直射 / 漫射：覆盖加权 + 云修正因子 + 能量守恒

```python
# 云量是"覆盖率"而不是"光学厚度"：太阳有 c 的时间被挡住
T_dir(c) = (1 - c) + c * exp(-TAU_CLOUD_THICK)
#    c=0 → 1.00   c=0.5 → 0.525   c=0.85 → 0.190   c=1 → 0.050

# 云修正因子（Badescu/Kasten 型）：地表总辐照相对晴空的比值
CMF(c) = 1 - 0.75 * c**3.4
#    c=0 → 1.00   c=0.5 → 0.93     c=0.85 → 0.57    c=1 → 0.25

# 能量守恒：总辐照预算 - 直射的水平分量 = 漫射
beam    = clear_beam * T_dir(c) * T_aerosol(vis)
diffuse = max(clear_diffuse, GHI_clear*CMF(c)*T_aerosol(vis) - beam*sin(alt))
```

`haze/fog` 的能见度通过 Koschmieder 关系变成气溶胶消光，**同时削减直射与总辐照**
（`astro.vis_transmittance()`），不再和"云"混在一起。

### 3.3 其余光质：全部推导，没有表

| 量 | 推导式 |
|---|---|
| `hardness`（光硬度） | `beam / (beam + diffuse)`，即直射占比 |
| `contrast`（对比度） | `1 - 0.30·(1 - hardness)`，硬光→高对比，软光→低对比 |
| `wet`（湿面） | `1 - exp(-precip / 0.5)`，降水率→水膜覆盖率 |
| `bounce`（地面反弹） | 地面状态（雪/湿/干）→ 反照率；气温 < 2℃ 且有降水才是雪 |
| `airlight`（空气光） | `1 - exp(-(3.912/vis) · room_d)`，用**真实室内光程** |
| `saturation` | `1 + 0.10·wet - 0.20·airlight`（湿更艳、雾更灰） |
| 色温 | 沿用 `astro.weather_color_shift()`（Rayleigh/Mie 分波长） |

### 3.4 视觉适应曝光（Levenson/Stevens）

```python
EV = (E_ref / E) ** EYE_ADAPT_GAMMA        # E_ref = 晴天正午 ≈ 1.0
EV *= 平滑权重（太阳 < 10° 时淡出）           # 暮光/夜间：夜就是夜，不提亮
→ 在 ACES 之前乘到线性辐照度上
```

### 3.5 窗口是面光源（`aperture_illuminance`）

```python
E ∝ A_win * cosθ_win * cosθ_wall / r²      # 全部量都来自真实几何
```
均值归一化（只重新分配光、不改总曝光）。这是"靠窗亮、离窗暗"的来源，
也是阴天画面不再是一块平灰的原因。

### 3.6 阵雨 / 雷阵雨的间歇性（`astro.shower_dynamics`）

`burst = 时间轴值噪声(t, 周期 26min / 雷雨 17min)`（**确定性哈希，同刻必同结果**）

```python
cloud_eff  = c·(0.40 + 0.60·burst) + (100-c)·0.55·burst   # burst=0 时云量低于基准 → 露出太阳
precip_eff = precip·(0.15 + 2.60·burst)
```

### 3.7 夜间

```python
night_sky_irradiance = 0.008·(1 - 0.55·cloud)                      # 星空/城市辉光
                     + 0.035·moon_brightness(phase)·alt_n·(1-0.6c)  # 月光散射
```
随月亮高度、月相、云量变化 → 夜景会演化，不再是死帧。

## 五、自测守门（`tools/selftest_verify.py` G1–G12）

物理量必须满足**单调性 / 守恒 / 有界**，否则直接失败：

- G1 云透过率单调递减，`T(0)=1`、`T(100)≈5%`
- G2 云修正因子单调递减，全阴 ≈ 0.25（实测世界 20%~30%）
- G3 晴天下直射≈晴空值且漫射不被吞掉（守恒）
- G4 厚阴天直射几乎消失、漫射占主导
- G5 地面反弹：雪 0.80 > 干 0.25 > 湿 0.07
- G6 雪天判定需要气温 < 2℃（旧版缺 temp 的回归测试）
- G7 水膜覆盖率单调饱和在 [0,1]
- G8 室内空气光必须很小（雾天 600m / 4m 光程 < 5%）—— 防止再"硬凑雾感"
- G9 曝光适应：阴天 > 1、晴天 ≈ 1、**夜间 = 1**
- G10 WMO 码分类：95→雷阵雨、80→阵雨、73→雪
- G11 阵雨云量随时间起伏，且同刻可复现
- **G12 全局手调参数 ≤ 5 且无隐藏可调量**（架构约束）
