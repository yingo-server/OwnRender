# 依赖与安装

---

## 1. 预装库（只有 3 个）

| 库 | 版本要求 | 用途 | 是否必需 |
|---|---|---|---|
| **numpy** | ≥ 1.20 | 全部数值运算（光照、光线追踪、图像处理） | **必需** |
| **Pillow** | ≥ 8.0 | 图像读写、字体渲染、滤镜、重采样 | **必需** |
| **requests** | ≥ 2.20 | AI 生成、NTP 校时、IP 定位、天气查询 | 可选* |

\* 只有走「离线光照 + 叠字」或「自定义图片 + 叠字」时，**完全不需要 requests**。
程序不会因为 import 失败而崩溃 —— 相关功能会自行降级。

### 开发环境实测版本

```
Python 3.12.3
numpy   2.5.3
Pillow  12.3.0
requests 2.34.2
```

## 2. 安装

### 方式 A：pip

```bash
python -m pip install numpy Pillow requests
```

### 方式 B：uv（推荐，快很多）

```bash
# 安装 uv
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

cd OwnRender
uv venv
uv pip install numpy Pillow requests
# 之后用 .venv 里的解释器运行
.venv/bin/python main.py
```

### 方式 C：系统包管理器

```bash
# Debian / Ubuntu
sudo apt install python3-numpy python3-pil python3-requests

# macOS (Homebrew)
brew install python numpy pillow
pip3 install requests

# Termux
pkg install python-numpy python-pillow
pip install requests
```

### Android / proot (Ubuntu)

```bash
apt-get update
apt-get install -y python3 python3-pip
pip install numpy Pillow requests --break-system-packages
```

> `proot` 环境建议用 `uv` + `--link-mode copy`（部分挂载盘不支持符号链接）。

## 3. 第一次运行

```bash
python main.py
```

首次启动会在 `config/` 下自动生成三个配置文件：

```
config/
├── settings.json    渲染默认值
├── lighting.json    光照与 3D 场景系数
└── prompts.json     AI 提示词
```

`config/` 目录**不会**被提交到仓库（见 `.gitignore`），里面可能存放 Token 等凭据。

## 4. 离线 vs 在线

| 能力 | 离线 | 在线 |
|---|---|---|
| 光线追踪物理光照 | ✅ | — |
| 文字叠字 / 年代感 | ✅ | ✅ |
| 用 `background/` 内置底图 | ✅ | ✅ |
| 用自己导入的图片 | ✅ | ✅ |
| AI 生成底图 | ❌ | 需要 Token |
| NTP 精确校时 | ❌（用系统时间） | 需要网络 |
| IP 定位 | ❌ | 需要网络 |
| 实时天气查询 | ❌（用预设/手动） | 需要网络 |

**推荐起步路径**：完全离线跑通 → 需要 AI 生成时再配 Token。

### 配 Token（仅 AI 模式需要）

可以在三个地方设置，优先级从高到低：

1. 命令行 `--token sk-xxxx`
2. 环境变量 `AGNES_API_TOKEN`
3. `config/token.json` 里的 `api_token`（设置中心可写入，权限 600）

TUI：`设置 → 凭据 → 设置 / 更换 API Token`，自带连通性测试。

## 5. 平台注意事项

| 平台 | 注意点 |
|---|---|
| **Windows** | 控制台若不支持 ANSI，程序会自动降级为无色；也可用 `--no-color` |
| **macOS** | 系统自带 Python 可能缺包，建议用 Homebrew Python |
| **Linux** | 无 systemd 的容器里，时区回退到 `/etc/timezone` 或 `TZ` 环境变量 |
| **Termux** | 装 `termux-api` 才能用 `termux-location` 取本机定位 |
| **proot / 容器** | 若无外网，请只用离线模式；定位可用 `--set-location` 手写 |
| **低内存设备** | SSAA 8x 在 1312×736 底图上会分配约 10k×6k 的灰度画布（约 60MB），可降到 `--ssaa 4` |

## 6. 卸载 / 重置

```bash
# 只删渲染产物
rm -rf output/

# 重置全部配置（会丢失 Token、提示词自定义等）
rm -rf config/
```

也可以在 TUI 里：`设置 → 恢复出厂`。
