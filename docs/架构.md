# 架构

---

## 1. 三个子框架

代码按职责分成三个**互相隔离**的子框架，只通过 `config` 横向共享常量：

```
frame_interact/   交互层：TUI、参数向导、设置、CLI、两种模式编排
      │  调用
      ├──────────────► frame_light/    光照层：天文 → 光照参数 → 窗格几何 → 光线追踪
      └──────────────► frame_render/   渲染层：Retinex → 材质 → 编排 → 文字叠字 → 编码
```

**依赖方向是单向的**：`interact → light/render`；`light` 与 `render` 之间
**不互相 import**（`frame_render/pipeline.py` 通过延迟 import 使用 light 的场景数据），
以避免循环依赖。

## 2. 模块清单

### frame_light/ — 光照

| 文件 | 职责 |
|---|---|
| `astro.py` | 太阳/月亮位置、大气散射、天气获取、**跨环境定位 provider**、时区 |
| `light.py` | 主入口 `compute_light()`：把"时间+位置+天气+窗向"变成一组光照物理量 |
| `geometry.py` | 窗格几何：光斑中心/大小/剪切/半影/阴影偏移，并乘**入射因子** |
| `scene3d.py` | 3D 房间与相机、`win_bbox`（窗户在墙面上的投影框） |
| `raytrace.py` | 光线追踪：直接光 + 阴影 + 半影 + 环境光（天光） |
| `scene.py` | 场景光构成（含城市光等） |
| `utils.py` | 角度/方位措辞等小工具 |

### frame_render/ — 渲染

| 文件 | 职责 |
|---|---|
| `pipeline.py` | **总编排**：Retinex → 材质 → 追踪 → ACES → 相机效果 → 曝光/饱和 → 编码 |
| `retinex.py` | 光照/反射率分解（把底图拆成 albedo 与原始光照） |
| `material.py` | PBR 五通道材质提取（albedo/roughness/height/water…） |
| `text.py` | 文字 SSAA、年代感、接触阴影、物理光学合成 |
| `compose.py` | sRGB 编解码 |
| `patch.py` | 光斑贴图工具（历史遗留，当前主链路未用） |
| `utils.py` | 色彩空间、ACES、噪声、数组位移 |

### frame_interact/ — 交互

| 文件 | 职责 |
|---|---|
| `tui.py` | TUI 工具箱：颜色（CJK 宽字符对齐）、面板、菜单、输入原语、`Wizard`、`edit_mapping` |
| `wizard.py` | **参数向导**：`Plan` 全集 + 各步编辑器（文字/字体/排版/底图/时间/位置/天气/光照/渲染/年代感/画面/输出） |
| `settings.py` | 设置中心（8 组）+ 信息与自检 |
| `runner.py` | 主菜单、模式分发、`--set-location` 早退 |
| `cli.py` | argparse 参数表、模式判定 |
| `offline.py` | 离线光照模式与自定义图片模式编排 |
| `ai.py` | 在线 AI 生成模式编排 |
| `progress.py` | 进度条 / 阶段汇报 |

## 3. 数据流（离线光照模式）

```
┌─────────── 输入 ───────────┐
│ 平坦材质底图 + 文字          │
└────────────┬───────────────┘
             │
   ┌─────────▼─────────┐
   │ retinex.split()   │  分离：albedo（反射率） + S（原始光照）
   └─────────┬─────────┘
             │
   ┌─────────▼─────────┐
   │ material.extract()│  PBR：roughness / height / water …
   └─────────┬─────────┘
             │
   ┌─────────▼───────────────────────────────────────┐
   │ light.compute_light(lat, lon, time, weather,    │
   │                     window_orientation)         │
   │   → source / az / alt / irradiance / color      │
   │   → ambient（天光）                             │
   │   → patch 几何 + 阴影偏移                        │
   └─────────┬───────────────────────────────────────┘
             │
   ┌─────────▼─────────┐
   │ raytrace.trace()  │  3D 房间 + 窗户 → I_traced（线性光强）
   └─────────┬─────────┘
             │
   ┌─────────▼──────────────────┐
   │ ACES tone mapping          │
   │ + 相机效果（渐晕/CMOS/色偏） │
   │ + 曝光 / 饱和度             │
   └─────────┬──────────────────┘
             │
        ┌────▼────┐          ┌──────────────────┐
        │ lit.png │─────────►│  text.fuse()     │
        └─────────┘          │  SSAA→年代感→阴影 │
                             │  →乘性反射合成     │
                             └────────┬─────────┘
                                      │
                                 ┌────▼─────┐
                                 │ final.png│
                                 └──────────┘
```

**光照与叠字严格分离**：光照只产出 `lit.png`，叠字只消费 `lit.png`。
好处是"改文字"不必重跑光线追踪。

## 4. 关键算法与公式

### 4.1 太阳位置

标准低精度天文算法（年积日 → 赤纬与均时差 → 时角 → 方位角与高度角）。
实测精度：北京 2025-06-21 正午，计算高度角 `73.53°`，
理论值 `90° − |39.9° − 23.44°| = 73.54°`（误差 0.01°）。

### 4.2 大气质量与透过率（分波长）

Kasten-Young 大气质量：

```
AM = 1 / (sin(alt) + 0.50572 · (alt + 6.07995)^(-1.6364))
```

分波长透过率（Rayleigh + Mie）：

```
τ_R(λ) = 0.098 · (λ/550)^(-4.08)        # 蓝端散射更强
τ_M    = 0.05 + 云量项 + 能见度项        # 近似与波长无关
T(λ)   = exp( -(τ_R(λ) + τ_M) · AM )
```

结果：正午偏白，低太阳角**红通道透过率相对更高** → 自动偏橙红。

### 4.3 天光（漫射）

```
sky(sun_alt, cloud) = 0.22 · sin(alt)^0.6 · (1 − 0.70·(cloud/100)^1.8)
```

- 太阳在地平线下 → 0（暮光由独立分支处理）
- 作用：**即使没有直射光，白天墙面也会随时间/云量正确变亮变暗**

### 4.4 窗口入射因子

```
inc_factor = max(0.02, sqrt( max(0, cos(alt)·cos(az_rel)) ))
irradiance *= inc_factor
```

其中 `az_rel = 太阳方位 − 窗法线方位`。掠射（太阳接近窗平面）时趋近 0 ——
这就是"东窗正午几乎无直射"的来源。

### 4.5 光斑几何

```
cx = 0.5 − sin(az_rel)·0.35           # 水平偏移
cy = 0.55 − min(1, alt/60)·0.25       # 越高越靠上
stretch = window_aspect / tan(alt)    # 低太阳角 → 竖向拉伸
```

### 4.6 色调映射与画面微调

```
I_out = ACES(I_traced · gain)
I_out = camera_effects(I_out)          # 渐晕 / CMOS 曲线 / 阴影色偏
I_out = lum + (I_out − lum)·saturation # 线性域饱和
I_out = I_out · exposure
```

### 4.7 文字年代感

```
α = α₀ · (1 − low·(1−n_low)) · (1 − mid·(1−n_mid))     # 多频噪声调制
edge  = α − erode(α)                                    # 提取边缘
α     = α + edge · (n_high−0.5)·2·high                  # 边缘毛糙
α     = α + max(0, blur(α)−α) · diffusion               # 颜料扩散
α[氧化颗粒点] *= (1 − oxidation·0.5)                     # 氧化颗粒
```

### 4.8 合成（乘性反射）

```
L_out = L_wall·(1 − occ·s) · [(1−α) + α·ρ_cinnabar]
```

## 5. 配置体系

```
config.py
 ├─ FACTORY_SETTINGS   → config/settings.json
 ├─ FACTORY_LIGHTING   → config/lighting.json
 ├─ FACTORY_PROMPTS    → config/prompts.json
 └─ 顶层常量（颜色空间、年代感默认值、字体与断行辅助）
```

- `ensure_config_files()` 启动时自动补齐缺失键（**只加不改**）
- 运行时覆盖：`config.TEXT_MATERIAL_COUPLING`、`config.VISUAL_EXPOSURE/SATURATION`

## 6. 扩展点

| 想做的事 | 改哪里 |
|---|---|
| 加一种材质底图 | 图片丢进 `background/`（**不用改代码**） |
| 加一款字体 | 字体丢进 `fonts/`（**不用改代码**） |
| 加一个城市预设 | `wizard.py` 的 `CITY_PRESETS` |
| 加一种天气预设 | `config.WEATHER_PRESETS` + `wizard.WEATHER_UI` |
| 加一个定位来源 | `astro.py` 写一个 `_p_xxx()`，注册进 `LOCATION_PROVIDERS` |
| 改窗户几何（如加南北向） | `config.WINDOW_SIDE_AZ` + `scene3d` |
| 改默认渲染参数 | `config.FACTORY_SETTINGS` 或设置中心 |
| 改光照物理系数 | 设置中心 → 光照与 3D 场景（60+ 字段） |
| 改 AI 提示词 | 设置中心 → AI 提示词 |
| 加一条 CLI 参数 | `cli.py` 的 `build_parser()` + 在 `wizard.plan_from_args` 里接线 |

## 7. 已知的历史遗留

- `frame_render/patch.py` 的 `render_light_patch()` 与 `compose.synthesize()`
  在主链路中**未被调用**（早期"多层光斑合成"路线的残留，保留供参考）。
- 窗户朝向只支持 `left`/`right`（等价于西/东），尚无南北向。
- AI 模式生成的是"带光照的墙"，**不走**光线追踪，因此物理一致性弱于离线模式。
