# 命令行参数参考

`python main.py [参数…]`

> 不带任何参数 = 进入 TUI 主菜单。
> 带了参数但**没加 `-y`** = 先用参数预填**参数向导**，可临时修改后再生成。
> 加了 `-y` = 完全非交互，直接渲染。

## 1. 模式选择

| 参数 | 说明 |
|---|---|
| `--ai` | **AI 生成模式**：用提示词调图像模型生成带光照的墙面，再叠字。需要 Token 与联网。 |
| `--offline-bg NAME` | **离线光照模式**：用 `background/` 中的材质图，走**光线追踪**物理光照后叠字。 |
| `-i PATH` / `--input-image PATH` | **自定义模式**：任意图片，**不做光照**，只叠字。 |
| `--background NAME` | 指定底图名字（不含扩展名也可）。单独使用时**不会**触发离线模式，仅作为取值。 |
| `--keep-lit` | 保留中间光照底图 `*_lit.png`（默认渲染完成后删除）。 |

**模式判定优先级**：`-i` > `--offline-bg` > `--ai` > 其它生成参数（视为 AI）> 主菜单。

```bash
python main.py --offline-bg 微水泥 -y      # 离线光照
python main.py -i ./wall.png -y            # 只叠字
python main.py --ai -t "标题" -y            # AI 生成（需 Token）
```

## 2. 输入输出

| 参数 | 默认 | 说明 |
|---|---|---|
| `-t TEXT` / `--text TEXT` | `谎如昨日，嗤笑今朝` | 叠加的文字。可用 `\n` 显式换行；半角 `,` 会自动转全角 `，` 并分行 |
| `-o OUTPUT` / `--output OUTPUT` | `./output` | 输出目录（不存在会自动创建） |
| `--output-name NAME` | `LIT`（离线）/ `AI`（在线） | 文件名前缀 |

输出文件名：`{前缀}_{YYYYMMDD}_{HHMMSS}_final.png`

## 3. 文字与排版

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `-f FONT` / `--font FONT` | `fonts/` 下的文件名 | 自动 | 可写全名 `AaXiuKai-2.ttf` 或去扩展名 `AaXiuKai-2` |
| `--font-ratio F` | 0.02 – 0.60 | `0.18` | **字高占画面高度比例** |
| `--font-anchor A` | `center` `tl` `tr` `bl` `br` `tc` `bc` `lc` `rc` | `center` | 锚点（九宫格） |
| `--font-pos-x P` | 0 – 100 | `50` | 锚点横坐标（画面宽度的百分比） |
| `--font-pos-y P` | 0 – 100 | `50` | 锚点纵坐标 |
| `--ssaa N` | 1 – 16 | `8` | 文字超采样倍数（越大越锐、越慢、越吃内存） |

```bash
python main.py --offline-bg 红砖墙 -t "独立寒秋" --font-ratio 0.3 -y

python main.py --offline-bg 青砖墙 -t "海内存知己，天涯若比邻" \
    --font-anchor bc --font-pos-y 85 -y
```

## 4. 窗户几何与光照

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `--window-orientation` | `left` `right` | `right` | 窗户所在墙侧。`right`=东向（上午有直射），`left`=西向（下午有直射） |
| `--window-scale F` | 0.2 – 1.2 | `0.65` | 窗户相对房间的大小系数 |
| `--grid-rows N` | 1 – 8 | `3` | 窗格行数 |
| `--grid-cols N` | 1 – 8 | `2` | 窗格列数 |
| `--grid-frame F` | 0.02 – 0.5 | `0.18` | 窗框占比（决定光斑里"格线"的粗细） |
| `--shadow-length V` | `auto` 或 0.5 – 4.0 | `auto` | 阴影/光斑偏移倍率 |

**关键理解**：`--window-orientation` 决定"什么时候有直射光"。

- 东向窗（`right`）：**上午**有直射；正午几乎无（太阳接近窗平面）；下午太阳在窗背面 → 无直射
- 西向窗（`left`）：相反，**下午/黄昏**有直射

```bash
# 上午 9 点，东窗，晴天 → 有清晰光斑
python main.py --offline-bg 微水泥 --window-orientation right \
    --time "2025-06-21T09:00:00+08:00" --lat 39.9 --lon 116.4 --weather clear -y

# 黄昏 18:30，西窗 → 拉长的橙红光斑
python main.py --offline-bg 微水泥 --window-orientation left \
    --time "2025-06-21T18:30:00+08:00" --lat 39.9 --lon 116.4 --weather clear -y
```

## 5. 时间与位置

### 时间

| 参数 | 说明 |
|---|---|
| `--time S` | 时刻。**推荐写带时区偏移的 ISO 串**：`2025-06-21T12:00:00+08:00`。也接受 `YYYY-MM-DD HH:MM`（按本机时区解释） |
| `--no-ntp` | 不使用 NTP，直接用系统时间 |
| `--ntp-host HOST` | 指定 NTP 服务器（如 `pool.ntp.org`） |

> ⚠️ **时区很重要**：光照按 **UTC** 计算。若你的机器时区是 UTC，而你想要"北京中午"，
> 请写 `2025-06-21T12:00:00+08:00`；否则会被当成 UTC 12:00（＝北京时间 20:00，天已黑）。

### 位置

| 参数 | 说明 |
|---|---|
| `--lat F` / `--lon F` | 直接给经纬度（最可靠） |
| `--city NAME` | 城市名（仅作显示与记录） |
| `--gps` | 强制用**本机定位**（跨环境 provider 链） |
| `--ip-loc` | 强制用 **IP 网络定位** |
| `--no-gps` | 禁用自动定位（避免联网查询） |
| `--geo-service NAME` | 只用指定的 IP 定位服务 |
| `--set-location LAT,LON[,CITY]` | 把坐标写入本地缓存 `config/device_location.json`，以后 `--gps` 可直接命中；**写完即退出** |

**本机定位的 provider 链**（按顺序，失败自动降级）：

```
termux-location → Android(dumpsys/cmd) → Linux GeoClue
→ Linux gpsd → Linux ModemManager → macOS CoreLocation
→ Windows Geolocator → 时区推算 → 本地缓存
```

对应依赖：Termux 需 `termux-api`；Linux 桌面需 `geoclue-2.0` / `gpsd` / `modemmanager`；
macOS 需 `CoreLocationCLI`；Windows 需允许系统定位。

```bash
python main.py --set-location "39.9042,116.4074,北京"   # 写缓存后退出
python main.py --offline-bg 微水泥 --gps -y              # 用本机定位
python main.py --offline-bg 微水泥 --ip-loc -y           # 用 IP 定位
```

## 6. 天气

| 参数 | 取值 | 说明 |
|---|---|---|
| `--weather W` | `auto` `clear` `cloudy` `overcast` `rain` `snow` `haze` | 天气预设 |
| `--cloud F` | 0 – 100 | **云量 %**（覆盖预设） |
| `--precip F` | 0 – 50 | 降水量 mm |
| `--visibility F` | 200 – 50000 | 能见度 m |
| `--humidity F` | 0 – 100 | 湿度 % |

优先级：**命令行 > 设置里的默认值 > 预设**。

| 预设 | 云量 | 效果 |
|---|---|---|
| `clear` 晴 | 0% | 直射最强，光斑边界最锐 |
| `cloudy` 多云 | 45% | 直射减弱，光斑变软 |
| `overcast` 阴 | 90% | 几乎无直射，散射为主，低对比 |
| `rain` 雨 | 95% | 叠加水痕，光斑很模糊 |
| `snow` 雪 | 90% | 叠加雪花亮点，冷色 |
| `haze` 雾霾 | — | 能见度低，光斑明显模糊 |
| `auto` 自动 | — | 联网查当地实时天气（离线时回退晴天） |

```bash
python main.py --offline-bg 青砖墙 --weather cloudy --cloud 30 \
    --visibility 10000 --humidity 55 -y
```

## 7. 输出规格（AI 模式）

| 参数 | 取值 | 默认 |
|---|---|---|
| `-r` / `--resolution` | `1K` `2K` `3K` `4K` | `2K` |
| `-a` / `--aspect` | `1:1` `3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` | `16:9` |

> ⚠️ **4K 档位有速率限制（RPM=1，约每分钟 1 张）**，批量生成请用 `1K` / `2K`。
> 这两个参数**只对 AI 模式生效**；内置底图模式输出尺寸 ＝ 底图尺寸。

## 8. 渲染参数

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `--ssaa N` | 1 – 16 | `8` | 超采样倍数 |
| `--seed N` | 整数 | 随机 | 随机种子（固定它可复现同一张的噪声分布） |
| `--light-level N` | 0 – 12 | 自动 | 手动指定光照等级（0 最暗、12 最亮），覆盖自动分级 |
| `--wall-desc TEXT` | 字符串 | — | 直接描述墙材质（AI 模式用于拼提示词） |
| `--keep-lit` | flag | 关 | 保留中间光照图 |

---

## 9. 画面微调

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `--exposure F` | 0.2 – 3.0 | `1.0` | 线性域曝光倍率 |
| `--saturation F` | 0.0 – 3.0 | `1.0` | 饱和度（1=不变，0=灰度，>1=更艳） |

两者作用在 ACES 色调映射**之后**、sRGB 编码**之前**，不会破坏色调映射的高光滚降。

## 10. 物理参数（文字年代感）

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `--cinnabar R G B` | 0 – 1 各通道 | `0.52 0.055 0.048` | 朱红颜料**反射率**（乘性合成，不是普通叠色） |
| `--noise-low F` | 0 – 0.6 | `0.12` | 低频斑驳（大块透明度变化） |
| `--noise-mid F` | 0 – 0.6 | `0.10` | 中频斑驳 |
| `--noise-high F` | 0 – 0.6 | `0.06` | 高频毛糙（边缘颗粒） |
| `--diffusion F` | 0 – 0.8 | `0.20` | 颜料扩散（字沿墙纹扩散的程度） |
| `--oxidation F` | 0 – 0.8 | `0.30` | 氧化颗粒强度 |
| `--shadow-strength F` | 0 – 1.0 | `0.25` | 接触阴影强度 |
| `--material-coupling F` | 0 – 1.0 | `0.0` | **材质耦合**：字形透明度随墙面材质起伏（0=关闭） |

> 合成模型：`L_out = L_wall·(1 − occ·s)·[(1−α) + α·ρ]`
> 文字不是"盖"上去，而是作为**反射率层**乘在光照上，所以低光环境下字也会随之变暗。

## 11. 控制类

| 参数 | 说明 |
|---|---|
| `--token T` | 直接给 API Token（优先级最高） |
| `--settings` | 打开设置中心后退出 |
| `--no-color` | 禁用彩色输出（也支持 `NO_COLOR` 环境变量） |
| `-y` / `--yes` | **非交互**：跳过所有提问与参数向导 |
| `-v` / `--verbose` | 输出 DEBUG 日志 |
| `--log-level L` | `DEBUG` `INFO` `WARN` `ERROR` |
| `--log-file` | 同时写日志到 `config/logs/agnes-render.log` |
| `--dry-run` | 只打印将要做的事与预测，不实际渲染 |
| `--no-render` | 同理，只走到渲染前一步 |

## 12. 查询类

| 参数 | 输出 |
|---|---|
| `--list-fonts` | 字体列表 |
| `--list-backgrounds` | 底图列表（含尺寸） |
| `--list-sizes` | 分辨率档位 × 比例 → 像素尺寸对照表 |
| `--list-ntp` | NTP 服务器列表 |
| `--list-services` | IP 定位服务列表 |
| `--show-config` | 打印当前三份配置 + Token 掩码 |
| `--reset-config` | 恢复出厂设置（需确认） |
| `--version` | 版本号 |

查询类参数**不会**进入菜单，执行完即退出。

---

## 13. 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 / 正常退出 |
| `1` | 参数或流程错误（如找不到底图、位置解析失败） |
| `130` | 用户中断（Ctrl-C） |

## 14. 示例合集

```bash
# ① 最简离线
python main.py --offline-bg 微水泥 -y

# ② 上午晴天，东窗，北京，带时区
python main.py --offline-bg 青砖墙 \
    --time "2025-06-21T09:00:00+08:00" --lat 39.9042 --lon 116.4074 \
    --weather clear --window-orientation right -y

# ③ 黄昏西窗，长影橙光
python main.py --offline-bg 暖色夯土 \
    --time "2025-06-21T18:30:00+08:00" --lat 39.9042 --lon 116.4074 \
    --weather clear --window-orientation left -y

# ④ 阴天低对比
python main.py --offline-bg 粗灰泥 --weather overcast -y

# ⑤ 雨夜
python main.py --offline-bg 锈蚀钢板 \
    --time "2025-11-11T22:00:00+08:00" --lat 31.23 --lon 121.47 \
    --weather rain -y

# ⑥ 大字清晰题字
python main.py --offline-bg 大理石 -t "静水流深" \
    --font-ratio 0.30 --noise-low 0.05 --diffusion 0.10 --oxidation 0 -y

# ⑦ 斑驳旧标语
python main.py --offline-bg 旧石灰 -t "为人民服务" \
    --font-ratio 0.22 --noise-low 0.30 --diffusion 0.40 --oxidation 0.50 -y

# ⑧ 自定义图片只叠字（不光照）
python main.py -i ~/Pictures/wall.jpg -t "谎如昨日，嗤笑今朝" \
    --font-anchor center --font-pos-y 55 -y

# ⑨ 画面微调
python main.py --offline-bg 白色乳胶漆 --exposure 1.15 --saturation 0.9 -y

# ⑩ 用本地定位与实时天气
python main.py --offline-bg 微水泥 --gps --weather auto -y
```
