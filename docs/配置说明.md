# 配置说明

---

## 1. 三层配置体系

```
① 出厂默认（FACTORY_*，写死在 config.py 里）
        ↓ 被
② 用户设置（config/*.json，由设置中心或手改）
        ↓ 被
③ 命令行 / 参数向导（本次运行临时覆盖）
```

**优先级：③ > ② > ①**。命令行不写盘，只在本次运行生效。

---

## 2. 配置文件

首次运行自动生成在 `config/`：

| 文件 | 内容 | 怎么改 |
|---|---|---|
| `settings.json` | 渲染默认值：分辨率、比例、SSAA、字体、窗户、天气默认、曝光/饱和、材质耦合、日志级别、定位配置 | 设置中心 / 手改 JSON |
| `lighting.json` | 光照与 3D 场景系数：房间尺寸、相机、ACES 增益、天光目标亮度、渐晕、材质强度、年代感开关… | **设置中心（全部字段可改）** |
| `prompts.json` | AI 模式的提示词：墙材质、场景档案（按光照等级）、比例相关描述、禁止元素… | 设置中心 / 手改 JSON |
| `token.json` | API Token（仅 AI 模式）。文件权限自动设为 `600` | 设置中心 → 凭据 |
| `device_location.json` | 本机定位缓存（可选） | `--set-location` 或设置中心 |

> `config/` 已在 `.gitignore` 中排除；**不要**把它提交到仓库。

## 3. 设置中心（TUI）

主菜单 → `[3] 设置`：

```
设置中心
┌─ 当前概览 ─────────────────────────────────────────┐
│ 分辨率/比例  2K 16:9
│ 默认底图    （自动）
│ 字体/比例    AaXiuKai-2.ttf 0.18
│ 窗户       right 3x2
│ 天气默认    auto
│ 材质耦合    0.0
│ 曝光/饱和    1.0 / 1.0
│ Token      sk-tk9lV…M2Mh
│ 日志       INFO
└───────────────────────────────────────────────────┘
  设置分组
   ▸ [0] 渲染与输出
     [1] 光照与 3D 场景        ← 60+ 个物理/视觉系数，全部可改
     [2] 天气默认
     [3] 文字与年代感
     [4] AI 提示词
     [5] 凭据（Token / NTP / 定位）
     [6] 日志
     [7] 恢复出厂
```

- **光照与 3D 场景 / AI 提示词**：用通用编辑器列出**所有字段**（含子分组），
  自动识别 bool / int / float / list / str，改完立即保存，不藏参数。
- **天气默认**：预设 + 手动覆盖（云量/降水/能见度/湿度），留 `none` 表示"用预设"。
- **凭据**：Token（写入 + 连通性测试）、NTP 主机、IP 定位服务、
  **本机定位**（环境探测 / 重新获取 / 手动写入 / 勾选启用的来源 / su 提权 / 清除缓存）。

## 4. 命令行覆盖

任何设置都能被命令行临时覆盖，例如：

```bash
# 设置里默认 8x SSAA，本次想用 4x
python main.py --offline-bg 微水泥 --ssaa 4 -y

# 设置里默认晴天，本次想用雨天
python main.py --offline-bg 微水泥 --weather rain -y

# 设置里天气默认是 cloudy，但本次只改云量
python main.py --offline-bg 微水泥 --weather cloudy --cloud 10 -y
```

天气的取值优先链是**独立**的：

```
--cloud 参数  >  settings.json 里的 "cloud"  >  天气预设的 cloud
```

## 5. 手改 JSON 示例

### settings.json

```json
{
  "resolution": "2K",
  "aspect": "16:9",
  "ssaa": 8,
  "font": "",
  "font_ratio": 0.18,
  "font_anchor": "center",
  "font_pos_x": 50.0,
  "font_pos_y": 50.0,
  "background": "",
  "keep_lit": false,
  "window_orientation": "right",
  "window_scale": 0.65,
  "grid_rows": 3,
  "grid_cols": 2,
  "grid_frame_ratio": 0.18,
  "shadow_length": "auto",
  "weather_override": "auto",
  "smart_wrap": true,
  "visual_exposure": 1.0,
  "visual_saturation": 1.0,
  "material_coupling": 0.0,
  "location_providers": [],
  "location_use_su": false,
  "log_level": "INFO",
  "log_to_file": false,
  "ntp_host": "",
  "geo_service": ""
}
```

字段说明（挑重点）：

| 键 | 说明 |
|---|---|
| `background` | 默认底图名（不含扩展名）。留空＝启动时选第一张 / 走向导 |
| `weather_override` | 默认天气预设：`auto`/`clear`/`cloudy`/`overcast`/`rain`/`snow`/`haze` |
| `cloud` `precip` `visibility` `humidity` | 天气手动覆盖；`null` ＝不覆盖 |
| `visual_exposure` / `visual_saturation` | 画面微调默认值 |
| `material_coupling` | 材质耦合强度默认值（0=关闭） |
| `location_providers` | 启用的定位来源列表，如 `["termux","android","timezone"]`；**空数组=全部按优先级** |
| `location_use_su` | Android 上是否允许用 `su -c` 执行 `dumpsys location` |
| `smart_wrap` | 断行是否按标点拆分（默认 true） |

### lighting.json（节选）

```json
{
  "scene": {
    "room_w_m": 4.0, "room_h_m": 3.0, "room_d_m": 4.0,
    "window_side": "right",
    "window_w_m": 1.2, "window_h_m": 1.5,
    "window_cy_m": 1.5, "window_cz_m": 1.5,
    "grid_rows": 3, "grid_cols": 2, "grid_frame_ratio": 0.10,
    "camera_pos_m": [0.0, 1.5, 3.0], "camera_fov_deg": 60
  },
  "aces_gain": 1.25,
  "ambient_target_sun_max": 0.45,
  "ambient_target_sun_min": 0.28,
  "ambient_target_twilight": 0.20,
  "ambient_target_moon": 0.17,
  "ambient_target_none": 0.15,
  "vignette_strength": 0.15,
  "material_strength": 0.8,
  "aged_enabled": true,
  "shadow_blue_tint": 0.05
}
```

> 这些是**物理/视觉系数**，改动会直接影响成图。建议用设置中心改（带当前值提示），
> 不合适时 `设置 → 恢复出厂` 即可回滚。

## 6. Token 的三种来源

优先级：`--token` > 环境变量 `AGNES_API_TOKEN` > `config/token.json`。

```bash
# 临时用一次
python main.py --ai -t "标题" --token sk-xxxx -y

# 长期：写进环境变量
export AGNES_API_TOKEN="sk-xxxx"
```

> 设置中心写入 `token.json` 时会自动 `chmod 600`。

---

## 7. 恢复与备份

```bash
# 备份
cp -r config config.bak

# 恢复出厂（删除全部用户配置）
python main.py --reset-config
# 或在 TUI：设置 → 恢复出厂
```

程序也具备**自愈**能力：若配置文件缺字段，启动时会自动补齐缺失键并回写
（不会覆盖你已有的值）。
