# 快速开始

5 分钟跑出第一张图。

---

## 0. 前置

- Python 3.9+
- 三个库：`numpy`、`Pillow`、`requests`

```bash
pip install numpy Pillow requests
```

> 只做**离线光照 + 叠字**其实完全不需要联网；`requests` 只在 AI 生成、
> NTP 校时、定位与天气查询时才用得到。

---

## 1. 跑起来

```bash
cd OwnRender
python main.py
```

出现主菜单：

```
┌──────────────────────────────────────────────────────────────────────────┐
│  agnes-render  ·  物理光照墙面渲染                                        │
│  v10.0.0   底图 16 张   字体 3 个   模式 AI / 离线 / 自定义                 │
└──────────────────────────────────────────────────────────────────────────┘
  主菜单
     [0] AI 生成底图 + 叠字          （在线，需要 Token）
   ▸ [1] 内置底图 + 物理光照 + 叠字   （离线）
     [2] 自定义图片 + 叠字            （离线，不光照）
     [3] 设置
     [4] 信息 / 环境自检
     [5] 退出
     回车=1     a/b/c/s/i/q 快捷选择
```

**第一次建议选 `[1]`**（离线），不需要任何 Token，也不消耗额度。

## 2. 参数向导

选完模式进入向导。它把一次生成涉及的**所有步骤一次列出**，你可以反复跳回去改：

```
   [0] 文字      谎如昨日， / 嗤笑今朝
   [1] 字体      AaXiuKai-2.ttf
   [2] 排版      比例0.18 center (50,50) SSAA8
   [3] 底图      微水泥.png
   [4] 时间      此刻 06-21 12:00 (UTC+8)
   [5] 位置      北京 (39.90,116.41)
   [6] 天气      clear
   [7] 光照      right 窗格3x2 阴影auto
   [8] 渲染      SSAA8 seed=None
   [9] 年代感    耦合0 扩散0.2 阴影0.25
   [10] 画面     曝光1 饱和1
   [11] 输出     ./output
────────────────────────────────────────────────────────────────────────────
  选择要修改的步骤（回车=确认）
     ...
   ▸ [12] ✓ 开始生成
     [13] 放弃
```

- 输入**编号**进入该步修改，改完自动回到总览
- **直接回车** = 用当前设置开始生成
- 想放弃就选 `[13]`

### 每一步做什么

| 步骤 | 说明 |
|---|---|
| **文字** | 叠在墙上的字。支持多行；半角逗号会自动转全角并分行 |
| **字体** | 从 `fonts/` 里选（带"当前"标记） |
| **排版** | 字号比例、锚点（九宫格）、位置百分比、超采样倍数 SSAA |
| **底图** | 从 `background/` 里选材质（仅离线模式） |
| **时间** | 当前时间 / 手动输入（含时区偏移）/ NTP 校时 |
| **位置** | 12 个城市预设 / 本机 GPS / IP 定位 / 手动经纬度 |
| **天气** | 7 预设 + 云量·降水·能见度·湿度手动微调，**带效果预测** |
| **光照** | 窗户朝向、尺寸、窗格行列、窗框占比、阴影倍率 |
| **渲染** | SSAA、随机种子、是否保留中间光照图 `lit.png` |
| **年代感** | 朱红反射率、噪声、扩散、氧化、接触阴影、材质耦合 |
| **画面** | 曝光、饱和度 |
| **输出** | 输出目录、文件名前缀 |

## 3. 天气怎么调

这是最好玩的一步。进入后会先给你**预设**，每个都标注了效果：

```
  天气
   ▸ [0] 自动（auto）      按季节/气候推算云量
     [1] 晴（clear）       云 0%，直射最强、光斑边界最锐
     [2] 多云（cloudy）    云 45%，光斑变软
     [3] 阴（overcast）    云 90%，几乎无直射、散射为主
     [4] 雨（rain）        云 95%，叠加水痕
     [5] 雪（snow）        云 90%，叠加雪花亮点
     [6] 雾霾（haze）      能见度低，光斑明显模糊
     [7] 手动微调（云量/降水/能见度/湿度）   完全放开
```

选 `[7]` 可以**逐项覆盖**（回车=保持；输入 `none` =回到用预设）。
改完立刻给出预测：

```
┌─ 效果预测 ──────────────────────────────────────────────┐
│ 云量/降水  30%  0.0mm  能见 10.0km  湿度 55%
│ 主光源     sun   高度 +37.3°   方位 +89.2°
│ 辐照度     0.5xx   天光 0.2xx
│ 可达性     阳光可达
└─────────────────────────────────────────────────────────┘
```

> "光斑预期/可达性"很关键：它会直接告诉你**这个组合下会不会有直射光斑**。

## 4. 等它跑完

渲染分两段，控制台会实时显示进度：

```
==> 光线追踪光照
  * Retinex 分解 ...
  * 平面波 ...
  + LIT_20250621_060000_lit.png (9.5s)
==> 文字叠字 8x
  * 底图 1312x736
  * 分配大画布 10496x5888
  ...
  + LIT_20250621_060000_final.png
==> 完成
```

产物在 `output/`：

| 文件 | 说明 |
|---|---|
| `LIT_*_lit.png` | 中间光照底图（**只在勾选"保留 lit.png"时留下**） |
| `LIT_*_final.png` | 最终成图（光照 + 叠字） |

文件名格式：`前缀_年月日_时分秒_final.png`。

## 5. 命令行等价写法

不喜欢交互？一次性敲完：

```bash
# 用默认底图、当前时间与位置，直接出图
python main.py --offline-bg 微水泥 -y

# 明确指定：2025-06-21 12:00（东八区），北京，晴
python main.py --offline-bg 微水泥 \
    --time "2025-06-21T12:00:00+08:00" \
    --lat 39.9042 --lon 116.4074 \
    --weather clear -y
```

- `-y / --yes`：跳过所有交互（非交互模式）
- 不加 `-y` 时，即使给了参数**也会先过一遍参数向导**（方便临时改），
  这是有意设计：命令行只是把值预填进去。
