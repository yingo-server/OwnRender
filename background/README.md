# 材质底图 / Background textures

本目录存放「离线光照」模式所用的**平光材质底图**。程序启动时自动扫描本目录
（不递归），支持扩展名：`.png .jpg .jpeg .webp .bmp`。

---

## 为什么必须是「平光」

管线会对底图做 **Retinex 分解**，把「反射率」与「原图光照」分离，再由光线追踪
**重新打光**。

如果底图自带方向光（比如一侧亮一侧暗、有窗影、有明显明暗渐变），就会与管线
重光照**冲突**：重光照后四角被抬亮、中心被压低，整体被"拉平"，细节在但观感差。

所以底图的要求是：

- ✅ 均匀柔和的**漫反射平光**
- ✅ 无方向光、无阴影、无高光、无明暗渐变
- ✅ 正视、无透视、满版铺满整面墙
- ✅ 纹理细节充足
- ❌ 没有窗户、窗框、门、家具、人物、植物、画框、灯具、开关、装饰物

> 自检技巧：对图片取「中心区亮度 vs 四角区亮度」，两者差值应尽可能小
> （好底图通常 < 15/255）。差值很大说明自带光照。

## 生成方式

这 16 张图由 **AI 图像模型**按统一提示词生成，便于复现：

- 模型：`agnes-image-2.1-flash`
- 请求尺寸：`2048x1152`（实际返回 1312×736）
- 提示词模板：

```text
正面拍摄的整面{材质名}墙面部特写：{细节描述}。
纹理丰富清晰、细节充足，均匀柔和的漫反射平光，
无方向光、无阴影、无高光、无明暗渐变、无景深虚化，
画面平整、满版铺满整面墙、正视无透视。
画面中只有这面墙与材质纹理，绝对没有窗户、窗框、门、
家具、人物、植物、画框、灯具、开关或任何装饰物。
建筑材质贴图，超高清晰度。
```

其中 `{细节描述}` 为该材质的特征短句（见上表"特征"列）。

> **声明**：AI 生成内容的法律定性因司法辖区而异，本项目不对其可版权性或
> 第三方权利作任何保证。如某张图与你的既有作品实质性相似，请提交 Issue 移除。

## 添加自己的底图

1. 把图片放进本目录（建议按材质命名，如 `石灰墙.png`）。
2. 确保是**平光**（见上文要求）；自带光照的图会与重光照冲突。
3. 运行 `python main.py --list-backgrounds` 确认已被识别。

```bash
# 用自己刚放入的底图渲染
python main.py --offline-bg 石灰墙 -y
```

### 尺寸与比例

程序会把底图**按原样**使用（不裁剪、不缩放），输出尺寸等于底图尺寸。
推荐 16:9 或 3:2 的横构图。`--resolution / --aspect` 只对**在线 AI 生成模式**
生效，不影响内置底图。
