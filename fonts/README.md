# 字体目录 / Fonts

## 怎么用

**TUI**：主菜单选模式 → 向导第 `[1] 字体` 步 → 从列表中选择。
字号比例 / 锚点 / 位置在 `[2] 排版` 步调整。

**命令行**：

```bash
# 指定字体文件名（不带目录）
python main.py --offline-bg 微水泥 -f AaXiuKai-2.ttf --font-ratio 0.18 -y

# 列出当前可用字体
python main.py --list-fonts
```

### 字号比例参考

`--font-ratio` 是**字高占画面高度的比例**：

| 值 | 效果 |
|---|---|
| 0.08 – 0.12 | 小字，画面留白多，适合长句 |
| 0.15 – 0.22 | 常用区间，两行题字 |
| 0.28 – 0.40 | 大字，视觉冲击强，建议配短句 |

## 常见问题

**Q：字体装了但列表里没有？**
检查扩展名是否在上面的支持列表内；文件名含中文/括号是允许的。

**Q：字体太大或太小？**
调 `--font-ratio`，不要改字体文件本身。程序会按画面高度自动换算字号。

**Q：`.ttc` 字体集怎么办？**
程序会自动使用 `index=0` 那一款；如需其它字重，请自行导出为 `.ttf`。

**Q：中文断行怪怪的？**
断行按标点（`，`）进行，行尾保留逗号。可用显式换行（`\n`）强制分行。
