# frame_light — 光照层

太阳位置、辐照度、天气、定位与逐像素着色。

| 文件 | 作用 |
|---|---|
| `astro.py` | 天文 + 物理 + 环境数据获取（太阳位置、分波长辐照度、天气、定位、NTP） |
| `light.py` | 光照编排 |
| `scene.py` | 4 层光照向量 |
| `scene3d.py` | 3D 场景建模 |
| `geometry.py` | 光斑几何 |
| `raytrace.py` | 逐像素着色（3D 场景 + 材质 + 物理反射） |
| `utils.py` | 公共工具 |

注意：`--time` 按 **UTC** 解释；日志中给出的是 UTC 时间与本机时区换算结果。
